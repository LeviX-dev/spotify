# Spotify-like Music Player (Static Web App)

A visually polished, responsive, and accessible Spotify-inspired music player built with HTML, CSS, and vanilla JavaScript.  
No backend required — ready for static hosting (Netlify, Vercel, GitHub Pages).

---

## 🚀 Features

- **Play/Pause, Seek, Volume, Mute/Unmute**
- **Playlist Management:** Create, rename, delete playlists
- **Recently Played:** Tracks update as you listen
- **Global Search:** Modal-based, responsive, Spotify-style search
- **Responsive Design:** Works on desktop, tablet, and mobile
- **Accessibility:** ARIA labels, keyboard navigation, semantic HTML
- **Trending & Marathi Sections:** Dynamic card generation
- **Production-Ready:** Minified assets, SEO meta tags, favicon

## 🛠️ Setup & Usage

1. **Clone or Download:**  
   Download the repository or copy the folder to your local machine.

2. **Open Locally:**  
   Open `index.html` in your browser.  
   No server or backend required.

3. **Static Hosting:**  
   Upload the folder to Netlify, Vercel, or GitHub Pages for instant deployment.
